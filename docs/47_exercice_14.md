# 236 — 0. Exercice 14

## 237 — 0.1 Modèles et automatisations

Écrivez vos réponses à ces questions dans un fichier texte. Pour les scripts et automatisations, inscrivez le code YAML généré.

Assurez-vous que votre nom apparaît dans le haut du fichier et que chaque question soit clairement identifiée.

Attention : le but de cet exercice est de vous pratiquer à écrire des modèles et à manipuler des dates, pas seulement d'obtenir une réponse. Si vous demandez de l'aide à votre IA favori, vous ne développerez pas vos habiletés.

Dans tous les cas, vous pourriez être convoqués pour expliquer votre code à votre prof. Assurez-vous de bien le comprendre.

1. Écrivez un modèle qui retourne la valeur d'un capteur virtuel booléen. Testez ce modèle dans les outils de développement. Modifiez sa valeur dans le tableau de bord et assurez-vous que le modèle reflète le changement.
2. Écrivez un modèle qui retourne true seulement si le capteur virtuel booléen est à true.
3. Écrivez un modèle qui retourne la valeur d'un de vos capteurs réels, par exemple la luminosité d'un capteur 5 en 1.
4. Écrivez un modèle qui retourne  « ouverte » ou « fermée » selon l'état d'un capteur d'ouverture de porte réel ou virtuel.
5. Écrivez un modèle qui retourne la valeur d'un capteur de votre choix multipliée par 5.
6. Écrivez un modèle qui retourne la température en fahrenheit à partir d'un capteur qui donne la température en celcius. Vous pouvez utiliser un capteur réel ou encore le capteur de météo.
7. Créez un capteur virtuel nommé Efforts. Il doit être en mesure de fournir un nombre situé entre 0 et 10. Associez ce capteur à l’icône « brain ».
8. Créez un récepteur virtuel textuel nommé Résultats. Associez ce récepteur à l’icône « chart-bell-curve-cumulative ».
9. Créez une automatisation nommée « Efforts influencent résultats » qui fait en sorte qu’à chaque fois que les efforts changent, les résultats prennent la valeur « Efforts \* 10 » suivi du signe %.
10. Écrivez un modèle qui calcule le nombre de jours restants avant Noël.
11. OPTIONNEL : ajoutez une carte sur le tableau de bord qui affiche le nombre de jours restants avant Noël. Suggestion : utilisez la [syntaxe Markdown](https://commonmark.org/help/) pour afficher le chiffre un peu plus gros.

13. Remettez votre fichier texte sur la plateforme électronique du cours.
