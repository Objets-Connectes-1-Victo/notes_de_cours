# 127. Interagir avec un objet connecté via son URL sous Jeedom {#chapitre-interagir_avec_un_objet_connecte_via_son_url_sous_jeedom}

## 127.1 Script qui interagit avec un objet connecté via son URL {#fiche-script_qui_interagit_avec_un_objet_connecte_via_son_url}

Sous Jeedom, le plugin Script, qui peut être [utilisé pour lancer un script Python](56_controle_gpio_avec_jeedom.md#fiche-lancer_un_script_python_avec_le_plugin_script), permet également d'interagir sur un objet à partir de son URL.

Ce peut être un objet qui est déjà pairé à votre boîte domotique Jeedom ou encore tout autre objet avec lequel on peut interagir à partir d'un URL.

Ceci permettra, par exemple, d'intégrer à votre boîte Jeedom des objets pairés avec une autre boîte domotique ou avec toute autre plateforme qui lui fournit un URL.
