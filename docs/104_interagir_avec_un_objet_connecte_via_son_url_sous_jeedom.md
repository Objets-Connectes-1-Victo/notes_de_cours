# 127. Interagir avec un objet connecté via son URL sous Jeedom

## 127.1 Script qui interagit avec un objet connecté via son URL

Sous Jeedom, le plugin Script, qui peut être [apical\_lien\_interne][lancer\_un\_script\_python\_avec\_le\_plugin\_script,utilisé pour lancer un script Python][/apical\_lien\_interne], permet également d'interagir sur un objet à partir de son URL.

Ce peut être un objet qui est déjà pairé à votre boîte domotique Jeedom ou encore tout autre objet avec lequel on peut interagir à partir d'un URL.

Ceci permettra, par exemple, d'intégrer à votre boîte Jeedom des objets pairés avec une autre boîte domotique ou avec toute autre plateforme qui lui fournit un URL.
